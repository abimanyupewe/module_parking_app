1. MAIN PROBLEM IDENTIFIED
================================================================================

ERROR: "databaseFactory is not initialized"
PLATFORM: Desktop only (Windows, Linux, macOS)
ROOT CAUSE: sqflite_common_ffi not initialized before database access
SEVERITY: CRITICAL (prevents app startup on desktop)

================================================================================
2. ROOT CAUSE ANALYSIS
================================================================================

sqflite package is a wrapper around SQLite:
- Mobile (Android/iOS): Native SQLite handled automatically
- Desktop (Windows/Linux/macOS): Requires FFI bridge initialization

Without initialization:
  app startup → SplashPage → database access → ERROR
  
With fix:
  app startup → main.dart init databaseFactory → ... → database access ✅

================================================================================
3. SOLUTION APPLIED (Commit f1d6e5a)
================================================================================

FILE: lib/main.dart (lines 20-25)

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // CRITICAL: Initialize FFI before any database access
  sqfliteFfiInit();
  
  if (Platform.isWindows || Platform.isLinux || Platform.isMacOS) {
    databaseFactory = databaseFactoryFfi;  ← KEY FIX
  }
  
  await AppPreferences.init();
  runApp(const MyApp());
}

TIMING: Must execute BEFORE AppPreferences.init() and runApp()
