CARA LOGIN:
===========

Option 1: Gunakan Quick Select Button
- Buka halaman Login
- Akan muncul 3 tombol: Owner, Admin, Petugas
- Klik tombol user yang ingin ditest
- Otomatis akan login dengan user tersebut

Option 2: Manual Input
- Masukkan username (owner / admin1 / petugas1)
- Masukkan password (123456 untuk semua)
- Klik Login

TESTING FLOW:
=============

1. Test Login dengan 3 user berbeda
   - Login sebagai Owner → lihat Owner Dashboard
   - Logout → Login sebagai Admin → lihat Admin Dashboard
   - Logout → Login sebagai Petugas → lihat Petugas Dashboard

2. Check Database
   - Buka DB Browser for SQLite
   - Buka parking_app.db
   - Lihat tabel tb_user, ada 3 user
   - Password sudah ter-hash dengan bcrypt (aman)

3. Test Session
   - Login sebagai owner
   - Tutup app sepenuhnya
   - Buka app lagi → langsung ke Owner Dashboard (session tersimpan)
   - Logout → kembali ke Login
   - Tutup app → buka lagi → kembali ke Login

4. Test Error Handling
   - Coba login dengan username yang salah
   - Coba login dengan password yang salah
   - Lihat error message yang muncul

CATATAN:
========
- Semua 3 user sudah aktif (status = 'aktif')
- Password: 123456 untuk semua user (untuk testing ease)
- is_default_password = 0 (sudah "diganti", tidak perlu reset)
- Setiap user punya security_question & security_answer (untuk future forgot password feature)
