LOGIN & REGISTRATION GUIDE
==========================

REGISTRATION (Owner Only)
=========================
Owner dapat melakukan registrasi sendiri melalui aplikasi:

1. Klik tombol "Daftar" di halaman login
2. Isi form:
   - Nama Lengkap (required)
   - Username (minimum 3 karakter, harus unik)
   - Password (minimum 6 karakter)
   - Konfirmasi Password
3. Klik "Daftar"
4. Jika berhasil, otomatis diarahkan ke login
5. Login dengan username dan password yang baru didaftar

CATATAN: 
- Hanya OWNER yang bisa register sendiri
- ADMIN dan PETUGAS tidak bisa register (dibuat oleh system admin)
- Password di-hash dengan bcrypt (aman)

LOGIN FLOW
==========

1. Aplikasi dibuka → cek session (SharedPreferences)
   - Jika sudah login → langsung ke dashboard sesuai role
   - Jika belum login → tampilkan login page

2. Di login page ada 2 opsi:
   a. Sudah punya akun? Login dengan username & password
   b. Belum punya akun? Klik "Daftar" untuk register (Owner only)

3. Setelah login berhasil:
   - Simpan session (SharedPreferences)
   - Redirect ke dashboard sesuai role
   - Catat activity di database

AUTHENTICATION DETAILS
=======================

Login Process:
- Validasi username & password tidak kosong
- Query user dari database
- Verify password dengan bcrypt
- Check status akun (harus 'aktif')
- Jika semua OK → simpan session & redirect

Registration Process (Owner only):
- Validasi: nama, username, password, confirm password
- Check: username belum terdaftar
- Hash password dengan bcrypt
- Insert user dengan role='owner', status='aktif'
- Redirect ke login page

Session Management:
- Menggunakan SharedPreferences
- Simpan: isLoggedIn, userId, userRole, username
- Session persistent (tetap aktif meski app ditutup)
- Logout: hapus semua session

DATABASE
========

Lokasi: /home/clara/Project/FLutter/basic_flutter/module_parking_app/parking_app.db

Tabel TB_USER:
- id_user (primary key)
- nama_lengkap
- username (unique)
- password (hashed with bcrypt)
- role (owner / admin / petugas)

- security_answer

- Password tidak pernah disimpan plain text (always hashed)
