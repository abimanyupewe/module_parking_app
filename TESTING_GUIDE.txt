HOW TO TEST:
============

Step 1: Test Login dengan Existing Users
- Run aplikasi
- Login: owner / 123456
- Lihat console output:
  * DEBUG LOGIN: User: UserModel(...)
  * DEBUG LOGIN: Role: Owner
  * DEBUG LOGIN: Role == "Owner": true
- Jika berhasil login → Owner Dashboard muncul

Step 2: Test Registration
- Logout
- Klik "Daftar"
- Isi form:
  * Nama: John Parkir
  * Username: johnparkir
  * Password: password123
  * Confirm: password123
- Klik "Daftar"
- Lihat console output untuk:
  * DEBUG: Starting registration for username: johnparkir
  * DEBUG: Username is available
  * DEBUG: Password hashed
  * DEBUG: Inserting user to database...
  * DEBUG: Insert result: [some number > 0]
  * DEBUG: User inserted successfully with ID: [number]

Step 3: Verify Data in Database
- Buka terminal/command prompt
- cd ke project folder
- Run: sqlite3 parking_app.db
- Query: SELECT username, role FROM tb_user WHERE username = 'johnparkir';
- Expected output: johnparkir|Owner

Step 4: Test Login dengan Registered User
- Close app sepenuhnya
- Run ulang app
- Login: johnparkir / password123
- Lihat console output untuk role check
- Jika role adalah 'Owner' → harus navigate ke Owner Dashboard

TROUBLESHOOTING:
================

Issue: "Role user tidak dikenali"
→ Check debug output untuk lihat actual role value
→ Biasanya null atau lowercase role

Issue: "Username sudah terdaftar" saat register
→ Ada username duplicate
→ Coba dengan username berbeda

Issue: Data tidak bertambah di database
→ Check debug output "Insert result: [number]"
→ Jika 0 atau -1, insert gagal
→ Lihat exception di console

Issue: Login fails dengan "Username tidak ditemukan"
→ Username tidak ada di database
→ Coba registrasi dulu, atau gunakan existing user (owner)
